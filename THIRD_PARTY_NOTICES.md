# Third-Party Notices

Pullio uses external software and libraries. Before a public binary release, keep the
license texts/notices that apply to the exact versions you distribute.

## yt-dlp
Project: https://github.com/yt-dlp/yt-dlp

Pullio launches the official/local `yt-dlp.exe` executable.
Do not remove yt-dlp's own license/notices from any redistributed package.

## FFmpeg
Project: https://ffmpeg.org/

The license obligations depend on the exact FFmpeg build and enabled components.
Before distributing `ffmpeg.exe` / `ffprobe.exe`, verify the license of the exact
build you ship and include the corresponding notices/source offer when required.
